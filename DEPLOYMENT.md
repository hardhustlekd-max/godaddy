# GoDaddy Deployment Guide\n\n## Prerequisites\n\n- Node.js 18+ on GoDaddy server\n- npm/yarn package manager\n- Firebase service account JSON\n- Google Generative AI API key\n\n## Quick Start\n\n### 1. Clone repository\n```bash\ngit clone https://github.com/hardhustlekd-max/godaddy.git\ncd godaddy\n```\n\n### 2. Install dependencies\n```bash\nnpm install\n```\n\n### 3. Configure environment\n```bash\ncp .env.example .env\n# Edit .env with your Firebase and API credentials\n```\n\n### 4. Build application\n```bash\nnpm run build\n```\n\n### 5. Start server\n```bash\nnpm start\n```\n\n## Production Deployment with PM2\n\n```bash\nnpm install -g pm2\npm2 start dist/server.cjs --name \"permitfinal\"\npm2 save\npm2 startup\n```\n\n## Nginx Reverse Proxy\n\n```nginx\nserver {\n    listen 80;\n    server_name your-domain.com;\n\n    location / {\n        proxy_pass http://localhost:3000;\n        proxy_http_version 1.1;\n        proxy_set_header Upgrade $http_upgrade;\n        proxy_set_header Connection 'upgrade';\n        proxy_set_header Host $host;\n        proxy_cache_bypass $http_upgrade;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n    }\n}\n```\n\n## Health Check\n\n```bash\ncurl http://localhost:3000/api/health\n```\n\n## Monitoring\n\n```bash\npm2 logs permitfinal\npm2 monit\n```\n\n## Troubleshooting\n\n- **Port in use:** `lsof -i :3000`\n- **Permissions:** `sudo chown -R www-data:www-data ./`\n- **Memory:** `pm2 monit`\n\n## SSL/TLS with Let's Encrypt\n\n```bash\nsudo apt install certbot python3-certbot-nginx\nsudo certbot --nginx -d your-domain.com\n```\n
